# Proposal: 表格列显示与列顺序

## Why

`CatTableView` 已支持排序、冻结、RTL、编辑和定制，但用户不能隐藏列或调整列顺序。商用表格需要按业务场景控制列集合，并且这些变化不能破坏 RTL 视觉列、冻结边界、排序和编辑映射。

## What Changes

- Gallery 增加应用层列配置代理：源模型 → 排序代理 → 列配置代理 → `CatTableView` → RTL 代理。
- 支持按源列显示/隐藏列，并至少保留一列可见。
- 支持按源列调整列顺序。
- 排序、表头指示器、选择恢复和列宽读写都经过列配置代理映射。
- Gallery 增加列复选框、左右移动按钮和重置按钮。
- 增加 C++ 代理单元测试和 Gallery QML 集成测试。

## Non-Goals

- 不把列可见性或列顺序状态放进 `CatTableView` 或公共库 ABI。
- 不实现冻结列拖拽排序、多列排序或列固定策略。
- 不改变排序代理和 RTL 代理现有职责。
