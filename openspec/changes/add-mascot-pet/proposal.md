# Proposal

## Why

QCatUiKit 已有主题控件和 Lottie 渲染，但缺少可由宿主事件驱动的桌宠窗口、角色包及动作调度契约。新增 MascotPet，使应用能复用角色展示与桌面交互能力，同时自行提供 Agent、TTS 和业务服务。

## What Changes

- 新增仅面向桌面悬浮的 MascotPet 组件，支持多个独立实例；不承诺页面内嵌公共组件。
- 支持声明式本地目录与 qrc 角色包，每包固定使用精灵图或 Lottie，包含动作、左右朝向、缩放锚点和命名交互区域。
- 提供替换、排队、忙时忽略的动作请求，以及可选拖拽动作抢占；通过公共事件向宿主报告完成、打断、交互和错误。
- 提供透明窗口、区域穿透与整窗穿透开关、拖拽、定位和平滑移动、多屏约束、可配置置顶与焦点策略。
- 提供纯文本气泡、增量更新、操作按钮、自动及手动关闭，以及可选且菜单可扩展的托盘。
- 提供状态导出／恢复和平台能力诊断；宿主负责持久化及进程退出。
- 同期目标平台为 Windows、macOS、Linux X11、原生 Wayland 的 KDE Plasma/KWin 与 GNOME/Mutter；接受配套扩展或辅助组件。先做平台原型，允许分阶段验收，未实机通过的平台不得宣告完整支持。

### Non-Goals

不实现 Agent 接入、TTS、音频采集分析或播放、连续口型参数、自主行走、物理模拟、逐帧透明度检测、混合渲染角色包、压缩包导入、网络下载、包内脚本或多桌宠互动管理器。

## Capabilities

### New Capabilities

- `mascot-pet`: 桌宠角色包、渲染、动作、宿主接口、气泡、实例及状态契约。
- `mascot-desktop`: 桌宠窗口、平台适配、输入区域、移动、托盘和实机验收契约。

### Modified Capabilities

无。复用 vector 与基础控件的现有契约，不改变其要求。

## Impact

拟新增 `src/uikit/mascot/` 及 CatMascotPet QML 窗口组件，更新模块 CMake、公共头安装与类型注册；平台适配保持私有，Wayland 配套代码按桌面环境隔离。精灵播放组合 Qt Quick 现有能力，Lottie 复用 CatLottieAnimation；不新增渲染引擎。

后续实现需增加 Gallery 外部事件驱动演示、两类示例角色包、中文／英文翻译、行为测试、平台探针、安装消费者测试及专题文档。既有公共接口保持兼容；配套组件依赖与具体版本范围由前置原型确定并记录，不隐式安装或修改用户桌面。

本 change 已进入实现；2026-10-28 用户明确先推进角色包解析与播放，平台原型及实机验收保持待办。当前完成情况见 tasks.md 与 validation.md，未同步主规格。
